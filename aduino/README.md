# PuttingMater: Arduino IMU 기반 평균 속도 측정 시스템

## 프로젝트 요약
**Arduino Nano 33 BLE** 보드에 내장된 **IMU 센서**를 활용하여 수동 후진 움직임(예: 골프 퍼팅의 백스트로크)을 정확하게 감지하고, 해당 동작 구간의 **안정적인 평균 속도**를 측정하여 출력하는 임베디드 및 모바일 연동 시스템입니다.

## 주요 기술 스택 및 구현 내용

### 하드웨어 및 개발 환경
* **하드웨어:** Arduino Nano 33 BLE (IMU 센서)
* **개발 언어 (펌웨어):** C++ (Arduino)
* **개발 언어 (앱):** Java (Android)
* **개발 툴:** Arduino IDE, Android Studio

### 핵심 알고리즘 및 역할 (본인)
* **역할:** 센서 데이터 처리 및 속도 측정 알고리즘 개발
* **신호 처리 기술:** 센서 데이터의 정확성을 극대화하기 위해 다음과 같은 고급 필터링 기술 적용:
    * **중력 보정 (Gravity Correction):** 가속도계 데이터에서 중력 가속도 성분 제거.
    * **이동 평균 필터링 (Moving Average Filtering):** 센서 노이즈 감소.
    * **진동 감지 (Vibration Detection):** 불필요한 움직임이나 떨림 필터링.
