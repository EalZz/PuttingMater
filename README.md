# PuttingMater

퍼팅 스윙 시 측정된 속도를 기반으로 예상 비거리를 보여주는 프로젝트입니다.  
사용자가 반복적으로 스윙 감각을 익히고, 스윙 일관성을 확인할 수 있도록 설계되었습니다.

## 프로젝트 구성

- `aduino/`: Arduino Nano 33 계열 보드용 펌웨어 (IMU + BLE)
- `android/`: 안드로이드 앱 (BLE 수신, 비거리 계산, 히스토리 UI)

## 동작 개요

1. 아두이노가 IMU 자이로/가속도 데이터를 읽어 스윙 구간을 감지합니다.
2. 스윙 종료 시점에 피크/평균 속도를 BLE characteristic으로 전송합니다.
3. 안드로이드 앱이 데이터를 수신해 비거리를 계산하고 메인/히스토리에 표시합니다.

## 주요 포인트

- BLE 장치명: `Putting Speed Meter`
- 스윙 측정값 노이즈 억제를 위한 스파이크 보정 버퍼 적용
- 비거리 계산은 피크 속도 기반으로 처리
- `재연결` 버튼에서 보드 `REBOOT` 명령 전송 후 자동 재스캔
- 히스토리 거리 표시는 메인 화면과 동일하게 `m` 단위 소수 1자리 표시

## 개발 환경

- Arduino IDE / arduino-cli
- Android Studio (Gradle, Java)

## 빠른 시작

### 1) 펌웨어

- `aduino/run_arduino.ps1`로 컴파일/업로드/모니터 실행
- 보드 포트와 FQBN은 환경에 맞게 스크립트에서 수정

### 2) 안드로이드 앱

- `android/`를 Android Studio로 열기
- BLE 권한 허용 후 장치 연결
- 스윙 측정 후 속도/비거리 확인
